# imgbit Homebrew tap

```sh
brew tap imgbit/tap
brew trust imgbit/tap        # Homebrew 7 and newer
brew install pipeline-monitor
```

Installed before Homebrew 7? Run `brew trust imgbit/tap` once, then
`brew upgrade`.

| Formula | |
|---|---|
| [pipeline-monitor](https://github.com/imgbit/pipeline-monitor) | See a running GStreamer pipeline live in your browser |
